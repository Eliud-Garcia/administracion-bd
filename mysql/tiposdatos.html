Tipo Categoría Uso Ejemplo
Numéricos enteros
TINYINTNúmeroEnteros muy pequeños (-128 a 127). Flags, estados simples.activo TINYINT(1)
SMALLINTNúmeroEnteros pequeños (-32768 a 32767). Ahorra espacio.edad SMALLINT
MEDIUMINTNúmeroRango medio (-8M a 8M). Poco común, entre SMALLINT y INT.visitas MEDIUMINT
INT / INTEGERNúmeroEnteros estándar. El más usado para IDs y contadores.id INT
BIGINTNúmeroEnteros muy grandes. Para IDs en tablas masivas.id BIGINT AUTO_INCREMENT
Numéricos decimales
DECIMAL / NUMERICNúmeroPrecisión exacta. Ideal para dinero y cálculos financieros.precio DECIMAL(10,2)
FLOATNúmeroPunto flotante de 4 bytes. Menos preciso, más rápido.temperatura FLOAT
DOUBLENúmeroPunto flotante de 8 bytes. Científico y estadístico.latitud DOUBLE
Texto y caracteres
CHAR(n)TextoLongitud fija. Rellena con espacios. Para códigos fijos.codigo CHAR(3)
VARCHAR(n)TextoLongitud variable con límite máximo de 65535. Campos de formulario.nombre VARCHAR(100)
TINYTEXTTextoTexto muy corto, máximo 255 caracteres.resumen TINYTEXT
TEXTTextoTexto mediano hasta 65535 caracteres. Descripciones, comentarios.descripcion TEXT
MEDIUMTEXTTextoTexto largo hasta 16MB. Artículos, documentos.contenido MEDIUMTEXT
LONGTEXTTextoTexto muy largo hasta 4GB. Logs, contenido masivo.log LONGTEXT
Fecha y hora
DATEFechaSolo fecha (año-mes-día), sin hora.nacimiento DATE
TIMEFechaSolo hora del día, sin fecha.hora_apertura TIME
DATETIMEFechaFecha + hora sin zona horaria. Rango 1000 a 9999.creado_en DATETIME
TIMESTAMPFechaFecha + hora con zona horaria. Rango 1970 a 2038.actualizado TIMESTAMP DEFAULT NOW()
YEARFechaSolo el año (4 dígitos). Para año de publicación, graduación, etc.anio_publicacion YEAR
Booleano
BOOLEAN / BOOLBooleanoAlias de TINYINT(1). 0 = falso, 1 = verdadero.activo BOOLEAN DEFAULT 1
Binario
BINARY(n)BinarioBytes de longitud fija. Similar a CHAR pero en binario.hash BINARY(16)
VARBINARY(n)BinarioBytes de longitud variable. Hashes, tokens.token VARBINARY(255)
TINYBLOBBinarioDatos binarios hasta 255 bytes.icono TINYBLOB
BLOBBinarioDatos binarios hasta 65KB. Imágenes pequeñas, archivos.imagen BLOB
MEDIUMBLOBBinarioDatos binarios hasta 16MB. Archivos medianos.archivo MEDIUMBLOB
LONGBLOBBinarioDatos binarios hasta 4GB. Videos, archivos grandes.video LONGBLOB
JSON
JSONJSONAlmacena JSON validado. Disponible desde MySQL 5.7.metadata JSON
Especiales
ENUMEspecialLista cerrada de valores. Estados, roles, categorías fijas.genero ENUM('M','F','Otro')
SETEspecialPermite múltiples valores de una lista. Permisos, etiquetas.permisos SET('leer','escribir','admin')
