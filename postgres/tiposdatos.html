Tipo Categoría Uso Ejemplo
Numéricos
smallintNúmeroEnteros pequeños (-32768 a 32767). Ahorra espacio.edad SMALLINT
integer / intNúmeroEnteros estándar. El más usado para IDs y contadores.id INT
bigintNúmeroEnteros muy grandes. Para IDs en tablas masivas.visitas BIGINT
numeric / decimalNúmeroPrecisión exacta. Ideal para dinero y cálculos financieros.precio NUMERIC(10,2)
realNúmeroPunto flotante de 4 bytes. Menos preciso, más rápido.temperatura REAL
double precisionNúmeroPunto flotante de 8 bytes. Científico y estadístico.latitud DOUBLE PRECISION
serialNúmeroEntero autoincremental. Clásico para claves primarias.id SERIAL PRIMARY KEY
bigserialNúmeroAutoincremental grande. Para tablas con millones de filas.id BIGSERIAL PRIMARY KEY
Texto y caracteres
char(n)TextoLongitud fija. Rellena con espacios. Para códigos fijos.codigo CHAR(3)
varchar(n)TextoLongitud variable con límite. Campos de formulario.nombre VARCHAR(100)
textTextoSin límite de longitud. Descripciones, artículos, logs.contenido TEXT
Fecha y hora
dateFechaSolo fecha (año-mes-día), sin hora.nacimiento DATE
timeFechaSolo hora del día, sin fecha.hora_apertura TIME
timestampFechaFecha + hora sin zona horaria. Timestamps locales.creado_en TIMESTAMP
timestamptzFechaFecha + hora con zona horaria. Recomendado para APIs.actualizado TIMESTAMPTZ
intervalFechaDuración de tiempo. Para calcular diferencias o plazos.duracion INTERVAL
Booleano
booleanBooleanoVerdadero/falso/nulo. Flags, estados activos/inactivos.activo BOOLEAN DEFAULT true
Binario
byteaBinarioDatos binarios crudos. Archivos, imágenes pequeñas, hashes.imagen BYTEA
JSON
jsonJSONAlmacena JSON como texto. Valida sintaxis al insertar.config JSON
jsonbJSONJSON binario indexable. Más eficiente para consultas.metadata JSONB
Red
inetRedDirección IPv4 o IPv6 con máscara opcional.ip_cliente INET
cidrRedRango de red (bloque CIDR). Para reglas de firewall.subred CIDR
macaddrRedDirección MAC de tarjeta de red.mac MACADDR
Identificadores
uuidEspecialIdentificador único universal de 128 bits. Ideal para sistemas distribuidos.id UUID DEFAULT gen_random_uuid()
Arrays
tipo[]EspecialArray de cualquier tipo. Etiquetas, permisos, listas.tags TEXT[]
Enumerados
enumEspecialLista cerrada de valores. Estados, roles, categorías fijas.estado tipo_estado
Geométricos
pointGeoPunto (x, y). Coordenadas simples.ubicacion POINT
polygonGeoPolígono cerrado. Zonas geográficas básicas.area POLYGON
