Tipos de datos — Oracle Database

Tipo Categoría Uso Ejemplo
Numéricos
NUMBER(p,s)NúmeroTipo numérico universal. p = precisión total, s = decimales. Para dinero, cantidades e IDs.precio NUMBER(10,2)
INTEGERNúmeroAlias de NUMBER(38). Enteros sin decimales. Estándar ANSI SQL.cantidad INTEGER
SMALLINTNúmeroAlias de NUMBER(38). Entero pequeño. Compatible con estándar SQL.edad SMALLINT
FLOAT(p)NúmeroSubtipo de NUMBER con precisión en binario. Para cálculos científicos.resultado FLOAT(10)
BINARY_FLOATNúmeroPunto flotante IEEE 754 de 32 bits. Más rápido que NUMBER.temp BINARY_FLOAT
BINARY_DOUBLENúmeroPunto flotante IEEE 754 de 64 bits. Alta precisión y rendimiento.latitud BINARY_DOUBLE
DECIMAL(p,s)NúmeroAlias de NUMBER(p,s). Compatibilidad con el estándar ANSI SQL.saldo DECIMAL(15,4)
Texto y caracteres
VARCHAR2(n)TextoCadena variable. El tipo de texto más común en Oracle. Obligatorio indicar tamaño.nombre VARCHAR2(100)
CHAR(n)TextoLongitud fija. Rellena con espacios. Para códigos o valores de tamaño siempre igual.codigo CHAR(3)
NVARCHAR2(n)TextoVARCHAR2 con soporte Unicode (AL16UTF16 / UTF8). Texto multilingüe.descripcion NVARCHAR2(200)
NCHAR(n)TextoCHAR de longitud fija con soporte Unicode. Para códigos internacionales.pais NCHAR(2)
Fecha y hora
DATEFechaFecha y hora (sin fracciones de segundo). El tipo temporal más usado en Oracle.nacimiento DATE
TIMESTAMP(fs)FechaFecha y hora con fracciones de segundo de hasta 9 dígitos.creado_en TIMESTAMP(6)
TIMESTAMP WITH TIME ZONEFechaTIMESTAMP con información de huso horario. Para aplicaciones globales.evento TIMESTAMP WITH TIME ZONE
TIMESTAMP WITH LOCAL TIME ZONEFechaTIMESTAMP normalizado al huso horario de la base de datos al consultar.log_ts TIMESTAMP WITH LOCAL TIME ZONE
INTERVAL YEAR TO MONTHFechaPeríodo expresado en años y meses. Para plazos y contratos.vigencia INTERVAL YEAR(2) TO MONTH
INTERVAL DAY TO SECONDFechaPeríodo en días, horas, minutos y segundos. Para duraciones exactas.tiempo INTERVAL DAY TO SECOND
Large Objects (LOB)
CLOBLOBCharacter Large Object. Texto muy largo: documentos, logs, XML, HTML. Hasta 128 TB.contenido CLOB
NCLOBLOBCLOB con soporte Unicode. Para texto largo en múltiples idiomas.descripcion NCLOB
BLOBLOBBinary Large Object. Imágenes, archivos, multimedia. Hasta 128 TB.imagen BLOB
BFILELOBApuntador a archivo externo en el sistema de archivos del servidor. Solo lectura.doc BFILE
Binario / RAW
RAW(n)BinarioDatos binarios de longitud variable. Sin conversión de charset. Máx. 2000 bytes.hash RAW(32)
LONG RAWBinarioBinario hasta 2 GB. Obsoleto — usar BLOB en diseños nuevos.datos LONG RAW
Identificadores y especiales
ROWIDEspecialDirección física única de una fila en la base de datos. Solo lectura.SELECT ROWID, nombre FROM empleados
UROWIDEspecialIdentificador universal de fila. Compatible con tablas index-organized y externas.fila UROWID
BOOLEANEspecialVerdadero/falso/nulo. En PL/SQL siempre; en SQL a partir de Oracle 23c.activo BOOLEAN DEFAULT TRUE
XML y JSON
XMLTYPEXML/JSONAlmacena documentos XML nativamente. Permite consultas XPath y XQuery.datos XMLTYPE
JSONXML/JSONTipo nativo para documentos JSON. Almacenamiento y consulta eficiente (Oracle 21c+).metadata JSON
Obsoletos (evitar en diseños nuevos)
LONGObsoletoTexto hasta 2 GB. Obsoleto — usar CLOB en su lugar.notas LONG
